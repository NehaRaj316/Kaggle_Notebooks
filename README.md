# Kaggle Notebooks 🚀

A collection of my Jupyter notebooks, code solutions, and experiments for various [Kaggle](https://www.kaggle.com) competitions and data science projects.

## 📂 Structure
* **Competitions/** - Code and solutions for specific Kaggle challenges.
* **Datasets/** - Data exploration and feature engineering scripts.
* **Practice/** - Notebooks exploring different machine learning techniques, models, and libraries.

## 🛠️ Tech Stack
* Python
* Jupyter Notebooks
* Pandas, NumPy, Scikit-Learn, TensorFlow / PyTorch
